# 验证记录与边界

本文记录项目可以公开复核的功能证据和仍需按设备复测的边界，不包含测试者的设备标识、账号、原始测量、抓包或签名资料。测试者应将自己的原始日志留在 Git 忽略的 `device-logs/`。

## 回归检查

```sh
swift test
xcodegen generate
xcodebuild -project S400WakeProbe.xcodeproj -target S400WakeProbe \
  -configuration Debug -sdk iphoneos \
  S400_APP_BUNDLE_ID="your.unique.bundle.id" DEVELOPMENT_TEAM="YOUR_TEAM_ID" build
```

在真机测试时，先确认设备、token 和用户资料属于自己；再分别核对秤面体脂/心率是否完整、App 是否收到同一轮结果、本人筛选是否正确，以及仅获授权的 HealthKit 类型是否写入。测试后台场景时，记录实际锁屏、踩秤和打开 App 的时间，并以日志中的连接、初始化、保存事件核对；`appState=background` 自身不是锁屏证明。

不要把 token、MAC、账号、含数值的测量 journal、原始抓包或完整诊断包上传到公开仓库。诊断事件可以用于确认流程，但应先检查并脱敏。
